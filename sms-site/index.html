What you receive

A proposed quantity, field priority, work cutoff, and a unique plan code. Reply APPROVE code to approve that version, or EDIT code quantity to request a change. A changed plan needs fresh approval. The prototype uses sample farm records and does not provide crop-safety or agronomic advice.
